# 使用量 / 单卡流向 口径收尾：Side 证据与「没有局次就忽略」（2026-11-11）

> **最终口径**：三条入口（QQ `使用量`、QQ `单卡流向`、网页按人）现在同一份代表构筑 —— 每人「最近一场有确证首局的比赛的第 1 局」。
> **主卡** = 首局张数；**备牌** = 第 2/3 局相对首局的**净换入**（录像没有备牌表）；**合计** = 主卡 + 换入（下界）。
> **没有局次信息的录像一律不进统计**（全局，不是某一条命令）。
> 生产：`ygo-web` + `ygo-qq` 已加载，health=200；GitHub `238425f`。

## 1. 背景：同一天、同一张卡、差 4 倍

```
使用量 古遗物-圣枪   有构筑 100/100；主卡 16 张；0张92人 1张1人 2张6人 3张1人   → 8 人
单卡流向 古遗物-圣枪  有构筑 100/100；带卡 2/100 人                              → 2 人
```

## 2. 两个根因

**2.1 `使用量` 用「最近一局」当代表构筑**（已修）

`card_usage_pie._latest_builds()` 按 `replays.recorded_at DESC` 取最近一局，通常落在 BO3 第 2/3 局——那是**换过 Side 的卡表**（换入的牌进 `main` 分区，换出的牌不在卡表里）。于是换入算成主卡、换出被抹掉；`单卡流向` 走 `population`/`latest_views`（首局优先），两边对不上。主卡必带卡（灰流丽/增殖的G）两条命令本来就一致，所以错长期只在换备用卡上暴露。

**2.2 备牌表在数据层不存在**

录像卡表块只有 `main` + `extra`，**没有 side 数组**（2026-11-11 实测两份：main 后面直接是下一位玩家的 main 数）。`statistics_facts.build_fingerprint()` 也写明「side 未在录像中完整公开」。因此 `stat_build_cards` 没有 `side` 分区、`side_complete` 恒 0——「备牌 0 人」只能是「未观测」。

**数据来源只有录像**：客户端只上传 `.yrp`，系统没有卡表 / YDK / 构筑上传接口（小世界 YDK 只在浏览器内计算；`stat_manual_decks` 只是命名标签）。所以备牌表**不可能**从外部补（详见 `DECK_BUILD_SIDE.md` §0）。

## 3. 最终口径

| 项 | 规则 |
|---|---|
| 代表构筑 | 每人「最近一场**有确证首局**的比赛」的第 1 局（`stats_population.latest_views`） |
| 主卡 | 该首局构筑里这张卡的主卡张数 |
| 备牌 | `max(0, 第 2/3 局最多张数 − 首局张数)`（与「换备」同规则：对比第 1 局、不链式、同场不累加） |
| 合计 | 主卡 + 备牌（下界；未换入 ≠ 没带） |
| 没有局次 | `eligible_views` 统一丢弃 `game_no` 缺失的视角（线上 892/13,860 = 6.4%）；没有任何有效场次的玩家不进分母 |

## 10. 边界与不再做的事

1. 未换入 ≠ 没带：side 里带了、整场没换进来的卡看不到；
2. 备牌表永远拿不到（录像无 side 数组、无卡表上传），「换入证据」就是上限；
3. 不按时间猜局次：没有 capture/唯一 `replay_sessions` 关联的场次直接忽略；
4. 主卡只认确证首局，不再用「最新观测」兜底。

## 11. 单卡流向的呈现规则（2026-11-11 10:20 定稿）

维护者要求「三张图左右看太费劲、条形太长、卡组太多、不能省略」，最终形态：

- **一张图三栏**：主卡（确证首局）/ 备牌（换入证据）/ 合计（主卡+换入）；**左右两侧都标卡组名**（右侧一份同样的标签，方便三栏对照），标签带 `(合计 used/known)`；
- **只有 ≥3 人的卡组画条形**（长度=该大类带卡率），**条内数字直接写玩家数**（如 `5人`，不再是百分比）；图幅约 1260×530；
- **≤2 人的卡组全部写进消息文本，不省略、不截断名字**，每个卡组一行：
  `卡组名 used/known：主卡 3张(2/2)；side 1张(1/2)；合计 3张(2/2)`
  （括号内是「有这么多张的玩家数 / 该卡组人数」，没有就写「无」、没有换备证据写「无证据」）；
- 例（决斗者之力，10:20）：图上 7 个 ≥3 人大类；文本列 35 个 ≤2 人卡组，例如
  `时黑道化一座混沌 1/1：主卡 2张(1/1)；side 1张(1/1)；合计 3张(1/1)`。
