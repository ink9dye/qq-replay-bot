# 小局计数

命令：

- `统计对局`：当前保留的去重小局总数，以及北京时间当天00:00起首次入库的小局数。
- `统计对局 关键词`：已识别卡组名包含关键词的小局数；例如关键词xx同时匹配xxyy、xxzz。双方均匹配时仍只算一个小局。
- `统计对局 前200`：至少一方当前有效名次在前200的已确认小局。
- `统计对局 前200 内战`：双方当前有效名次均在前200的已确认小局。

遵循现有命令可见范围，不在未允许会话中返回结果或帮助说明。

口径：只统计当前14天保留范围，不代表终身累计；同一录像指纹的多个副本仅算一个小局。今日按首次入库时间计算，不因重复副本再次计入。

当前官方公开榜单仅覆盖前100。前200查询复用已经发生的房间玩家查询结果（120秒内有效）及当前有效榜单，不发起新的逐人补查。若历史小局的参与者缺少当前名次，明确显示“已确认至少N”及未确认小局数，不能将部分结果作为完整前200总数，也不拿录制时的旧名次冒充当前名次。

资源限制：只读访问元数据表，不读录像文件、不卡表全量解析；查询串行、最多3秒、16项内存缓存、30秒有效，不落地统计副本或持续追加日志。房间名次样本复用原有采集状态写入，每次最多256条，不新增网络查询。
